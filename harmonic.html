What is Active Harmonic Filter

  1. Harmonics come from the nonlinear load. Active Harmonic filters also called harmonic correction unit are power electronic devices connected in parallel with the load to be compensated.
  2. They act like a noise cancellation system and inject equal and opposite frequencies to mitigate harmonics.
  3. The filters can also provide additional current to correct the power factor.
  4. So, what’s left coming from the source flowing back to the utility is only a nice, clean current that is in phase.

Working Principle of AHF

  1. Active Harmonic Filter is connected in parallel with non-linear loads, and uses one set of current transformers (CT) to detect the load current.
  2. It calculates each order harmonic current, and then generates a compensating current with the same amplitude but opposite phase angles to the detected harmonic current, which cancels out the original load harmonics.

Working Principle of AHF

  1. Active Harmonic Filter is connected in parallel with non-linear loads, and uses one set of current transformers (CT) to detect the load current.
  2. It calculates each order harmonic current and generates a compensating current with the same amplitude but opposite phase angle, cancelling the original harmonics.
  3. The AHF not only eliminates harmonic current from the load side, but also mitigates harmonic voltage caused by harmonic currents.
  4. The AHF system can also improve power factor (PF) and correct load imbalance in the power system.
1. DC Bus Capacitor

AC to DC rectifier storage. It provides stable DC voltage for inverter operation.

2. IGBT (DSP Controlled)

Controlled by DSP (Digital Signal Processing) algorithm. IGBT on-off timing and pulse width generate harmonic current. The square wave outline approximates a sinusoidal waveform.

3. Inverter Inductor

The square wave output converts into a triangular wave, making it closer to a sinusoidal waveform.

4. LC Filter Circuit

LC filter removes harmonic impurities from the current waveform.

5. High Frequency Inductor

High frequency harmonics are filtered using a high frequency inductor. LC Filter + High Frequency Inductor together form an LCL filter circuit.

Advantage of using AHF

  1. Wide Range of Harmonic Selection: Selec AHF’s cancel all odd harmonics up to 51st order. These harmonics are individually selectable without any limit on the number of harmonic selections at a time.
  2. Integrated Best in Class HMI: Selec AHF’s have integrated 4.3-inch touch screen HMI display to visualize and set AHF and plant parameters. Users can observe real-time three-phase voltage and current waveform.
  3. Optimum Design: Light in weight, compact in size, quieter in operation while delivering best-in-class performance.
